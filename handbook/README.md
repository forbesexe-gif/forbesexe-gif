# Public Engineering Handbook

A public reference for Jonathan Forbes's product, engineering, safety, and operations practices.

## Operating practices

- Separate implemented capabilities from plans
- Keep credentials and private data out of public artifacts
- Use small, reviewable, reversible changes

## Review standard

Changes should be evidence-based, scoped for review, explicit about limitations, and reversible where practical. Credentials, private infrastructure details, and unnecessary personal data must remain outside public artifacts.
