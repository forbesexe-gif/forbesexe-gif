# Support Operations

A method for triaging user reports, communicating status, and converting recurring problems into product improvements.

## Operating practices

- Classify severity, impact, ownership, and response target
- Protect private data in tickets and diagnostic bundles
- Link incidents, defects, documentation, and follow-up verification

## Review standard

Changes should be evidence-based, scoped for review, explicit about limitations, and reversible where practical. Credentials, private infrastructure details, and unnecessary personal data must remain outside public artifacts.
