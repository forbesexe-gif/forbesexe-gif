# Dependency Management

A supply-chain process for selecting, pinning, updating, and removing third-party software.

## Operating practices

- Prefer maintained dependencies with clear licenses
- Pin versions and review lockfile changes
- Track vulnerabilities, transitive risk, and replacement plans

## Review standard

Changes should be evidence-based, scoped for review, explicit about limitations, and reversible where practical. Credentials, private infrastructure details, and unnecessary personal data must remain outside public artifacts.
