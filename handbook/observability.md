# Observability

Metrics, logs, traces, health semantics, alerts, and audit records that make system state understandable.

## Operating practices

- Measure rates, latency, errors, saturation, and queue depth
- Disclose health-data age and scope
- Give every alert an owner and response action

## Review standard

Changes should be evidence-based, scoped for review, explicit about limitations, and reversible where practical. Credentials, private infrastructure details, and unnecessary personal data must remain outside public artifacts.
