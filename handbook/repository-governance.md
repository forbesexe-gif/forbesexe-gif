# Repository Governance

Standards for keeping repositories understandable, auditable, and safe to operate.

## Operating practices

- Document purpose, status, tests, deployment, and limitations
- Protect default branches for material projects
- Remove obsolete automation and temporary credentials

## Review standard

Changes should be evidence-based, scoped for review, explicit about limitations, and reversible where practical. Credentials, private infrastructure details, and unnecessary personal data must remain outside public artifacts.
