# Service-Level Objectives

A method for defining measurable reliability targets and using error budgets to guide delivery decisions.

## Operating practices

- Select user-centered availability and latency indicators
- State measurement windows, exclusions, and data quality
- Use error-budget consumption to trigger corrective work

## Review standard

Changes should be evidence-based, scoped for review, explicit about limitations, and reversible where practical. Credentials, private infrastructure details, and unnecessary personal data must remain outside public artifacts.
