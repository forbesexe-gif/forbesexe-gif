# Experimentation

A framework for hypotheses, metrics, guardrails, assignment, analysis, and decision-making.

## Operating practices

- Predefine success, harm guardrails, and stopping rules
- Protect assignment integrity and analyze uncertainty
- Record the decision, limitations, and follow-up measurement

## Review standard

Changes should be evidence-based, scoped for review, explicit about limitations, and reversible where practical. Credentials, private infrastructure details, and unnecessary personal data must remain outside public artifacts.
