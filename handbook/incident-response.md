# Incident Response

A containment-first process for unexpected behavior, security events, and operational failures.

## Operating practices

- Stop the affected capability while preserving evidence
- Separate confirmed facts from hypotheses
- Resume service only after remediation, testing, and accountable approval

## Review standard

Changes should be evidence-based, scoped for review, explicit about limitations, and reversible where practical. Credentials, private infrastructure details, and unnecessary personal data must remain outside public artifacts.
