# Security Baseline

Minimum controls that should exist before a project is exposed to users, data, or external services.

## Operating practices

- Apply least privilege and strong authentication
- Validate external input and redact sensitive logs
- Maintain tested backup, revocation, restore, and rollback procedures

## Review standard

Changes should be evidence-based, scoped for review, explicit about limitations, and reversible where practical. Credentials, private infrastructure details, and unnecessary personal data must remain outside public artifacts.
