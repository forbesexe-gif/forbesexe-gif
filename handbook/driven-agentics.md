# Driven Agentics

The parent product and research organization for independently developed AI-assisted software.

## Operating practices

- Define the user problem before selecting technology
- Give each product a clear repository and risk boundary
- Require evidence before calling a capability production-ready

## Review standard

Changes should be evidence-based, scoped for review, explicit about limitations, and reversible where practical. Credentials, private infrastructure details, and unnecessary personal data must remain outside public artifacts.
