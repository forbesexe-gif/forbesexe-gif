# Performance and Capacity

Measurement practices for latency, throughput, concurrency, resource use, and graceful degradation.

## Operating practices

- Define representative workloads and service-level objectives
- Profile before optimizing and preserve correctness
- Test saturation, backpressure, timeouts, and recovery

## Review standard

Changes should be evidence-based, scoped for review, explicit about limitations, and reversible where practical. Credentials, private infrastructure details, and unnecessary personal data must remain outside public artifacts.
