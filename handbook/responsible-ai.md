# Responsible AI

A control model in which AI may analyze and propose while deterministic systems govern authorization and side effects.

## Operating practices

- Treat model output as untrusted input
- Keep secrets and regulated data outside prompts
- Preserve human accountability for releases and irreversible actions

## Review standard

Changes should be evidence-based, scoped for review, explicit about limitations, and reversible where practical. Credentials, private infrastructure details, and unnecessary personal data must remain outside public artifacts.
