# Open-Source Readiness

A release gate for publishing code, documentation, issues, and community processes safely.

## Operating practices

- Remove secrets, private data, internal endpoints, and unsupported claims
- Choose a license and document contribution and security channels
- Provide reproducible setup, tests, scope, and maintenance expectations

## Review standard

Changes should be evidence-based, scoped for review, explicit about limitations, and reversible where practical. Credentials, private infrastructure details, and unnecessary personal data must remain outside public artifacts.
