# Documentation Quality

Standards for accurate, discoverable, maintained, and audience-appropriate technical documentation.

## Operating practices

- State current status, prerequisites, limitations, and ownership
- Test commands and examples against supported environments
- Archive or correct stale guidance promptly

## Review standard

Changes should be evidence-based, scoped for review, explicit about limitations, and reversible where practical. Credentials, private infrastructure details, and unnecessary personal data must remain outside public artifacts.
