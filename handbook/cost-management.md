# Cost Management

Controls for understanding and limiting infrastructure, data, API, model, and operational costs.

## Operating practices

- Attribute spend by project and environment
- Set budgets, alerts, quotas, and retention limits
- Evaluate unit economics before scaling

## Review standard

Changes should be evidence-based, scoped for review, explicit about limitations, and reversible where practical. Credentials, private infrastructure details, and unnecessary personal data must remain outside public artifacts.
