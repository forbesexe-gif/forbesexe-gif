# Project Evaluation

A rubric for judging problem clarity, feasibility, risk, validation, usability, reliability, economics, and status integrity.

## Operating practices

- Define evidence that could disprove the thesis
- Estimate build, hosting, data, support, and acquisition costs
- End reviews with proceed, revise, pause, or stop

## Review standard

Changes should be evidence-based, scoped for review, explicit about limitations, and reversible where practical. Credentials, private infrastructure details, and unnecessary personal data must remain outside public artifacts.
