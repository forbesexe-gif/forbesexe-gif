# Auditability

Records that make consequential actions attributable, reconstructable, and reviewable.

## Operating practices

- Capture actor, authority, input reference, policy decision, and outcome
- Use tamper-evident retention appropriate to risk
- Restrict audit access while preserving investigative usefulness

## Review standard

Changes should be evidence-based, scoped for review, explicit about limitations, and reversible where practical. Credentials, private infrastructure details, and unnecessary personal data must remain outside public artifacts.
