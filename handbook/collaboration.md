# Engineering Collaboration

Working agreements for ownership, communication, review, escalation, and shared technical context.

## Operating practices

- Make decision rights and interfaces explicit
- Use written proposals for consequential changes
- Resolve disagreements with evidence and documented tradeoffs

## Review standard

Changes should be evidence-based, scoped for review, explicit about limitations, and reversible where practical. Credentials, private infrastructure details, and unnecessary personal data must remain outside public artifacts.
