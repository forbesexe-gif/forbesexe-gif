# Privacy Review

A review process for personal data, user expectations, minimization, consent, retention, and disclosure.

## Operating practices

- Map collected data to a specific purpose
- Avoid unnecessary sensitive data in prompts, logs, and analytics
- Define access, retention, deletion, and incident obligations

## Review standard

Changes should be evidence-based, scoped for review, explicit about limitations, and reversible where practical. Credentials, private infrastructure details, and unnecessary personal data must remain outside public artifacts.
