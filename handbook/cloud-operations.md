# Cloud Operations

Operational practices for secure, observable, cost-aware cloud services.

## Operating practices

- Inventory and tag resources by project and environment
- Monitor capacity, errors, latency, storage, and certificate expiry
- Set cost alerts and test backup restoration

## Review standard

Changes should be evidence-based, scoped for review, explicit about limitations, and reversible where practical. Credentials, private infrastructure details, and unnecessary personal data must remain outside public artifacts.
