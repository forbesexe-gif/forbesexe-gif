# Logging and Privacy

A logging standard that preserves diagnostic value while minimizing sensitive data exposure.

## Operating practices

- Use structured events and stable identifiers
- Redact credentials, tokens, private content, and unnecessary personal data
- Set access, retention, deletion, and sampling rules

## Review standard

Changes should be evidence-based, scoped for review, explicit about limitations, and reversible where practical. Credentials, private infrastructure details, and unnecessary personal data must remain outside public artifacts.
