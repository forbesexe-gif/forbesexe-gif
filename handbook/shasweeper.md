# SHAsweeper

A cryptography and authorized-compute research project focused on transparent measurement and Bitcoin protocol study.

## Operating practices

- State the exact algorithm, workload, hardware, and method
- Do not label generic SHA-256 results as Bitcoin mining performance
- Use only owned or explicitly authorized compute resources

## Review standard

Changes should be evidence-based, scoped for review, explicit about limitations, and reversible where practical. Credentials, private infrastructure details, and unnecessary personal data must remain outside public artifacts.
