# KoalaWire

An authorized defensive security-analysis project for systems, applications, and code owned by the operator or covered by written permission.

## Operating practices

- Record authorization before assessment
- Prefer reproducible findings and remediation guidance
- Keep invasive capabilities disabled outside controlled test environments

## Review standard

Changes should be evidence-based, scoped for review, explicit about limitations, and reversible where practical. Credentials, private infrastructure details, and unnecessary personal data must remain outside public artifacts.
