# API Design

Standards for stable, understandable, and safely evolvable service interfaces.

## Operating practices

- Define schemas, authentication, errors, pagination, and versioning
- Make retries and idempotency explicit for write operations
- Document rate limits, deprecation, and compatibility guarantees

## Review standard

Changes should be evidence-based, scoped for review, explicit about limitations, and reversible where practical. Credentials, private infrastructure details, and unnecessary personal data must remain outside public artifacts.
