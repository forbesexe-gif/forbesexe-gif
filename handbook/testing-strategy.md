# Testing Strategy

Evidence-oriented testing across deterministic rules, interfaces, integrations, workflows, security, and operations.

## Operating practices

- Prioritize money, credentials, permissions, and irreversible actions
- Test retries, duplication, denial paths, and recovery
- Record commands, environments, results, and omissions

## Review standard

Changes should be evidence-based, scoped for review, explicit about limitations, and reversible where practical. Credentials, private infrastructure details, and unnecessary personal data must remain outside public artifacts.
