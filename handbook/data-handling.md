# Data Handling

Lifecycle controls for collecting, storing, using, exporting, retaining, and deleting data.

## Operating practices

- Minimize collection and classify sensitivity
- Encrypt sensitive data and restrict access by role
- Retain source, timestamp, transformation, and quality context

## Review standard

Changes should be evidence-based, scoped for review, explicit about limitations, and reversible where practical. Credentials, private infrastructure details, and unnecessary personal data must remain outside public artifacts.
