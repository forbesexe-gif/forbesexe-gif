# Technical Learning Roadmap

A practical path from systems fundamentals to programming, cloud operations, security, data, and applied AI.

## Operating practices

- Build fluency through small working projects
- Read generated code and predict behavior before running it
- Explain failures, fixes, evidence, and remaining uncertainty

## Review standard

Changes should be evidence-based, scoped for review, explicit about limitations, and reversible where practical. Credentials, private infrastructure details, and unnecessary personal data must remain outside public artifacts.
