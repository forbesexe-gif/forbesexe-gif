# Product Discovery

A disciplined process for validating problems, users, constraints, and value before scaling implementation.

## Operating practices

- Use interviews, observation, and behavioral evidence
- State assumptions and tests that could disprove them
- Prefer small validation loops over premature platform scope

## Review standard

Changes should be evidence-based, scoped for review, explicit about limitations, and reversible where practical. Credentials, private infrastructure details, and unnecessary personal data must remain outside public artifacts.
