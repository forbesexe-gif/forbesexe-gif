# Identity and Access

Controls for authentication, authorization, service identities, sessions, and administrative access.

## Operating practices

- Use least privilege and short-lived credentials
- Separate authentication from resource-level authorization
- Audit privileged actions and test revocation paths

## Review standard

Changes should be evidence-based, scoped for review, explicit about limitations, and reversible where practical. Credentials, private infrastructure details, and unnecessary personal data must remain outside public artifacts.
