# Model Evaluation

Evidence for judging model quality, reliability, cost, latency, safety, and operational fit.

## Operating practices

- Use representative tasks, fixed rubrics, and held-out cases
- Measure failure severity, variance, and abstention behavior
- Separate benchmark results from production claims

## Review standard

Changes should be evidence-based, scoped for review, explicit about limitations, and reversible where practical. Credentials, private infrastructure details, and unnecessary personal data must remain outside public artifacts.
