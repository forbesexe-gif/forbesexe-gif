# Release Management

A release process that includes scope, deployment, verification, monitoring, and recovery.

## Operating practices

- Record tests and untested conditions
- Prefer staged rollout and bounded exposure
- Verify the deployed commit and maintain a usable rollback path

## Review standard

Changes should be evidence-based, scoped for review, explicit about limitations, and reversible where practical. Credentials, private infrastructure details, and unnecessary personal data must remain outside public artifacts.
