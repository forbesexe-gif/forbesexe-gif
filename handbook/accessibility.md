# Accessibility

Design and validation practices that keep essential workflows usable with assistive technology and varied input methods.

## Operating practices

- Use semantic structure, labels, keyboard support, and visible focus
- Avoid color-only meaning and respect reduced motion
- Combine automated checks with manual keyboard, zoom, and screen-reader review

## Review standard

Changes should be evidence-based, scoped for review, explicit about limitations, and reversible where practical. Credentials, private infrastructure details, and unnecessary personal data must remain outside public artifacts.
