# Code Review

A review discipline focused on correctness, security, operability, maintainability, and evidence.

## Operating practices

- Review behavior and risk rather than formatting alone
- Require tests for material invariants and failure paths
- Resolve uncertainty before approving irreversible changes

## Review standard

Changes should be evidence-based, scoped for review, explicit about limitations, and reversible where practical. Credentials, private infrastructure details, and unnecessary personal data must remain outside public artifacts.
